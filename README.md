# SampleAIStore

SampleAIStore is a complete Next.js e-commerce starter with:
- Responsive landing + product catalog
- 3D interactive product demo (`react-three-fiber`)
- AR try-on entrypoint button (WebXR detection + fallback)
- Stripe Checkout integration via API route
- Vercel-ready deployment flow

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`.

## Deploy live URL

1. Push this repository to GitHub.
2. Import project in Vercel.
3. Add all variables from `.env.example`.
4. Deploy and use the generated `https://<project>.vercel.app` URL.
